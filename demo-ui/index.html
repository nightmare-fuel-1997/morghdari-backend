5 · Offboarding chain / زنجیرهٔ خروج عضو

Owner deactivates Session B's member → B refreshes (still valid!) → new token has NO org claim → B's reads return HTTP 200 with an EMPTY payload. No blacklist needed.

مالک عضوِ نشست ب را غیرفعال می‌کند؛ نوسازی بعدی توکنِ بدونِ سازمان می‌دهد و خواندن‌ها با کد ۲۰۰ و نتیجهٔ خالی انجام می‌شود — رفتار صحیحِ بسته-به-خطا (C-14).

  1. Login B as a normal member (step 1, slot B)
  2. Login A as the owner, press “Deactivate B” below
  3. Press “B: refresh & read” — watch authority vanish
