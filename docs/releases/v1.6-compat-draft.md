## 2. Changelog (draft — finalized in `CHANGELOG.md [1.6.0]` on ratification)

**Added**

- Compat REST surface (15 routes, §3 of the spec): orgs, org-single, org-farms, org-devices,
  farms list/single/farm-devices, devices list/single, org/farm/device latest + history.
- Farm-history envelope `{"farm_history": [...]}` on the farm-history route (exact key the
  shipped chart reads; raw array also accepted on the way in).
- Flat telemetry translation (`metrics`-map → `temperature`/`humidity`/`lux`/`nh3` strings,
  `server_received_ts` → `received_at`, `device_ts` → `sent_ts`, `device_slug` stamped).
- Farm WebSocket shim: one farm socket fans out to the farm's `saloon_*` groups, pushes
  flat-record JSON, honors `subscribe`/`unsubscribe` as TTL-refresh, closes `4003`/`4000`
  per current WS standards.
- `legacy_slug_map` additive table + idempotent backfill (+ `daily_report_extras` from the
  reports merge, Tracker §4s — the only schema additions; zero `ALTER`).

**Changed**

- `VERSIONS.md` §v0.6: compat layer recorded as v0.6 scope extension.
- `Open Items Tracker.md`: new §4o decision record (this release's authority).

**Deprecated**

- Nothing. Legacy `/api/...` (unversioned) aliases are supported, not deprecated, until the
  Flutter build migrates to `/api/compat/v1`.

**Fixed**

- Nothing in core behavior. All 48 `/api/v1` paths byte-identical.
