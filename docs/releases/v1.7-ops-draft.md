## 2. Changelog (draft — finalized in `CHANGELOG.md [1.7.0]` on ratification)

**Added**

- Pagination convention (`limit`/`offset` → `{results, count}`) for all v1.7.0+ lists.
- `GET /api/v1/audit-logs/` (owner/manager filterable query over `account_activity_logs`).
- `GET`/`PUT /api/v1/thresholds/` + `GET /api/v1/threshold-templates/` (engineer read, manager write, range-guarded).
- `GET`/`POST /api/v1/saloons/{id}/photos/` (first use of the frozen `saloon_photos` table).
- `GET /api/v1/gateways/` + `/{slot}/` + `/{slot}/diagnostics/` (manager/engineer reads; state changes stay in provisioning endpoints).
- `POST /api/v1/auth/password/change/` (with `3/min` strict throttle) + `GET`/`DELETE /api/v1/auth/sessions/` (new `user_sessions` table).

**Changed** — `VERSIONS.md` §v0.6 records v1.7.0 as a v0.6 scope extension; Tracker gains §4p.
