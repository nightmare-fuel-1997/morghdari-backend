## Open risks / follow-ups

- **TLS is the self-signed staging cert** (SAN `api.morghdari.com`/`mqtt.morghdari.com`, no IP SAN) — clients must use `-k` / skip-verify until a domain is pointed here and `scripts/tls_issue_vps.sh` (or the DNS-01 variant) is run. Port 80/443 are open for ACME webroot when a domain lands.
- **Rotate the root password and move to key-only SSH.** The supplied root password traveled in chat and was used once (key install); the deploy key `autoclaw-deploy` is authorized in `/root/.ssh/authorized_keys`. Suggested: add your own key, disable PasswordAuthentication in sshd_config.
- **No host firewall** (ufw inactive) — ports are controlled by exposure flags in compose; add ufw/nftables or a provider firewall group for defense-in-depth.
- **WAL archiving is off** (`WALG_S3_PREFIX` empty). Set real S3 vars before this host holds production data.
- **BUG-27 (dormant):** `EmqxQueueDropped` alert rule references a metric EMQX 5.5.1 doesn't export — monitoring gap, not a runtime fault.
- Celery/Redis health fields in `/health/` show `null` (no exporter wired) — cosmetic, containers themselves are healthy.
