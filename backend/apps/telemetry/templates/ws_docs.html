Morghdari WebSocket Protocol

Live dashboard sockets. REST is in Swagger; this page is the WS contract. Machine-readable mirror: /api/ws-schema/.

1. Endpoints

SocketPath
Saloon (canonical)WS /ws/saloons/{saloon_id}/telemetry?token=<JWT>
Farm (compat, Flutter)WS /ws/farms/{farmSlug}/telemetry?token=<JWT>
canonical twin: /api/compat/v1/ws/farms/{farmSlug}/telemetry?token=<JWT>

One socket per dashboard tab. Auth rides ?token= because browsers cannot set headers on the WS handshake. Connect is accept-then-close so the code reaches the client.

2. Close codes

CodeMeaning
4003Auth/org failure: missing or invalid token, token without org claim, unknown or foreign saloon/farm, or no ACTIVE membership. Re-login / check org.
4000Cap full: ws_max_connections_per_user slots already held (default 10). Close another tab, retry later.

3. Server messages

telemetry.hello (saloon connect)

{
  "type": "telemetry.hello",
  "saloon_id": 12,
  "org_id": "<org uuid>",
  "thresholds": {}
}

telemetry.update (live push, post-commit; metrics verbatim from stored row)

{
  "type": "telemetry.update",
  "saloon_id": 12,
  "slot_id": "GW-01",
  "device_ts": "2026-09-12T10:00:00Z",
  "is_buffered": false,
  "metrics": {"temp": {"avg": 24.5}, "humidity": {"avg": 62.0}}
}

telemetry.gap_fill (reply to gap_fill; ascending, max 200 rows)

{
  "type": "telemetry.gap_fill",
  "saloon_id": 12,
  "rows": [
    {"slot_id": "GW-01", "device_ts": "2026-09-12T10:00:00Z",
     "server_received_ts": "2026-09-12T10:00:02Z",
     "is_buffered": false, "metrics": {"temp": {"avg": 24.5}}}
  ]
}

telemetry.rejoined (late group-join after degraded handshake)

{
  "type": "telemetry.rejoined",
  "saloon_id": 12,
  "org_id": "<org uuid>",
  "thresholds": {}
}

connection_established (compat farm connect; buffered rows never pushed)

{
  "type": "connection_established",
  "farm_slug": "farm-01",
  "org_id": "<org uuid>",
  "saloon_count": 2
}

4. Client messages

Gap-fill (stateless — server holds no session, client merges by stamp):

{ "action": "gap_fill", "since": "2026-09-12T09:55:00Z" }

Compat subscribe (TTL heartbeat only):

{ "action": "subscribe" }

Any other inbound payload is ignored safely and still refreshes the cap TTL.

5. Snippets

JavaScript

const token = await getAccessToken(); // 15-min JWT
const ws = new WebSocket(
  `wss://${location.host}/ws/saloons/12/telemetry?token=${token}`
);
ws.onmessage = (ev) => {
  const msg = JSON.parse(ev.data);
  if (msg.type === "telemetry.update") onReading(msg);
  if (msg.type === "telemetry.gap_fill") mergeRows(msg.rows);
};
ws.onclose = (ev) => {
  if (ev.code === 4003) redirectToLogin();
  if (ev.code === 4000) toast("Too many tabs open");
  else setTimeout(reconnect, 2000);
};
// after offline: ws.send(JSON.stringify({action: "gap_fill", since: lastSeenIso}));

Dart (Flutter, compat farm socket)

final token = await getAccessToken();
final ch = WebSocketChannel.connect(Uri.parse(
  'wss://$host/ws/farms/$farmSlug/telemetry?token=$token'));
ch.stream.listen((raw) {
  final msg = jsonDecode(raw);
  if (msg is Map && msg.containsKey('sent_ts')) onFlatRecord(msg);
  if (msg['type'] == 'connection_established') onReady(msg);
}, onDone: () {
  if (ch.closeCode == 4003) redirectToLogin();
});

Do not use Swagger "Try it out" for these paths — it sends HTTP, not a WS handshake.
